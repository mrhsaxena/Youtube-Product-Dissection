# YouTube Product Dissection

## Project Overview
This project is a product dissection of YouTube, focusing on its features, business problems, database design, and SQL-based analysis.

## Objectives
- Understand YouTube's core features.
- Identify key problems and possible solutions.
- Design a simplified relational database schema.
- Understand relationships between database tables.
- Perform SQL queries for data validation and basic analysis.

## Database Schema
The project includes 8 tables:

1. Users
2. Channels
3. Videos
4. Comments
5. Likes
6. Subscriptions
7. Playlists
8. PlaylistVideos
